# MaximaLabs

Open tools for builders — agent infrastructure, MCP tooling, and cloud ops.

## Open source

| Project | What it is |
|---|---|
| [**dev-mcp-suite**](https://github.com/MaximaLabs/dev-mcp-suite) | Local, file-based MCP servers: persistent memory, session handoff, checkpoints, token-efficient briefings + optional fleet ops. `npx -y @maximalabs/dev-mcp-suite init` |
| [**armada**](https://github.com/MaximaLabs/armada) | Agent fabric across servers: append-only bus + `wr-node` daemon with a capability ladder (allow → user → root → sandbox). Zero-dependency Python. |
